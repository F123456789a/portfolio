# Personal Portfolio Website

A multi-page personal portfolio website built as part of **CS313: Web Engineering – Lab 3 (HTML Advanced - Personal Portfolio II)**.

## 📖 About

This project extends a basic HTML portfolio by adding external CSS styling, a proper folder structure, and deployment via GitHub Pages. It demonstrates layout techniques using CSS `float` and `clear` properties, along with clean project organization and version control.

## 🌐 Live Site

View the live portfolio here: **https://f123456789a.github.io/portfolio/**

## 📁 Project Structure

```
portfolio/
├── index.html          # Home page
├── hobbies.html         # Hobbies page
├── contact.html         # Contact page
├── gallery.html         # Image gallery page
├── skills.html           # Skills page
├── css/
│   └── style.css        # External stylesheet
├── images/
│   ├── photo1.jpg
│   ├── photo2.jpg
│   ├── photo3.jpeg
│   ├── photo4.jpg
│   └── photo5.jpg
└── README.md
```

## 📄 Pages

- **Home (index.html)** – Introduction and landing page
- **Skills (skills.html)** – Overview of technical and personal skills
- **Hobbies (hobbies.html)** – Interests and hobbies
- **Gallery (gallery.html)** – Image gallery styled with `float` and `clear`
- **Contact (contact.html)** – Contact information

## 🎨 Features

- Fully external CSS (no inline styling)
- Horizontally aligned navigation menu using CSS
- Image gallery laid out using `float` with `clear` to fix layout issues
- Consistent fonts, colors, borders, and spacing across all pages
- No JavaScript or CSS frameworks used, per lab requirements

## 🛠️ Tools Used

- HTML5
- CSS3
- Git & GitHub
- GitHub Pages (for deployment)
